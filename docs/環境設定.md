# 環境変数の設定手順

## 1. Supabaseの設定情報の取得
1. Supabaseプロジェクトの設定画面を開く
2. API > Project URL をコピー（SUPABASE_URL）
3. API > Project API keys > anon/public をコピー（SUPABASE_KEY）

## 2. 環境変数ファイルの作成
1. プロジェクトのルートディレクトリに`.env`ファイルを作成
2. 以下の内容を記述（値は実際の値に置き換え）:
```plaintext
SUPABASE_URL=your_supabase_url
SUPABASE_KEY=your_supabase_anon_key
```

## 3. 設定の確認
```powershell
python scripts/check_env.py
```

## 注意事項
- `.env`ファイルはGitにコミットしないでください
- 本番環境では適切な方法で環境変数を設定してください
- 環境変数の値は定期的に更新することを推奨します
