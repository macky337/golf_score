## バージョン管理の運用手順

### 1. コミットメッセージの規則
- `BREAKING CHANGE:` - メジャーバージョンアップ (v1.0.0 → v2.0.0)
  - 例：データベース構造の変更
  - 例：UIの大幅な刷新

- `feat:` - マイナーバージョンアップ (v1.0.0 → v1.1.0)
  - 例：新機能の追加
  - 例：既存機能の拡張

- その他 - パッチバージョンアップ (v1.0.0 → v1.0.1)
  - 例：バグ修正
  - 例：軽微な改善

### 2. コミット例
```bash
# メジャーバージョンアップ
git commit -m "BREAKING CHANGE: Supabaseへの移行"

# マイナーバージョンアップ
git commit -m "feat: バックアップ機能の追加"

# パッチバージョンアップ
git commit -m "fix: スコア計算のバグを修正"
