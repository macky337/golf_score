# Golf Score App

ゴルフコンペのスコア、ハンディキャップ、ゲームポイント、結果PDFを管理する Streamlit アプリです。スマホでの利用と、電波が弱いゴルフ場でのオフライン入力に対応しています。

## 主な機能

- ラウンド設定、参加メンバー、ゴルフ場、対戦ハンディキャップの登録
- OUT／IN／エキストラのスコア・パット・ゲームポイント入力
- マッチ対戦、パット、ゲームポイントの集計と結果確認
- 結果PDFの生成、ラウンド確定、ポイント集計
- オフライン用JSONによる現地入力と通信復帰後の同期
- 管理画面での修正、バックアップ、復元、ポイント診断

## 基本操作

通常の入力は次の順で行います。

1. 「ラウンド設定」で日付、ゴルフ場、参加メンバー、ハンディキャップを保存します。
2. 「フロントスコア入力」「バックスコア入力」でスコアを入力します。
3. 必要な場合だけ「エキストラスコア入力」を行います。
4. 「結果確認」で内容を確認し、PDFを生成してラウンドを確定します。

### 電波が弱い場所での入力

1. 出発前にラウンド設定を保存します。
2. 「オフライン入力」で、未確定ラウンドを選び、開始ファイル（JSON）をスマホへ保存します。
3. 現地で開始ファイルを読み込み、OUT・IN・エキストラを入力します。入力内容は端末内に保存されます。
4. ラウンド後に同期ファイル（`-sync.json`）を保存します。
5. 通信復帰後、「オフライン入力」で同期ファイルを選び、同期して結果を更新します。

開始ファイルを作成できるのは、ラウンド設定を保存済みで、まだ確定していないラウンドだけです。

## ローカル起動

Python 3 と仮想環境を用意し、依存関係をインストールします。

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
```

`.env` に最低限、次を設定します。値はリポジトリにコミットしません。

```text
SUPABASE_URL=...
SUPABASE_KEY=...
APP_USERNAME=...
APP_PASSWORD=...
ADMIN_PASSWORD=...
```

起動コマンドです。

```bash
.venv/bin/streamlit run main.py --server.address 127.0.0.1 --server.port 8502
```

ブラウザで `http://localhost:8502` を開きます。

## デプロイ

Railway は [railway.toml](railway.toml) を使い、`main.py` を Streamlit で起動します。GitHub の `main` へpushすると、RailwayのGitHub連携による自動デプロイが始まります。

Railway Variables に、ローカルと同じ認証・Supabase関連の環境変数を設定してください。

## 構成

- `main.py`：ホーム画面
- `pages/`：ラウンド設定、スコア入力、結果、管理などの画面
- `modules/`：認証、DB、集計、PDF、共通UI処理
- `static/offline-score/`：端末内で動くオフライン入力画面
- `sql/`、`alembic/`：DB設定・移行用
- `tests/`：自動テスト

DB修復・データ移行用の補助スクリプトは `scripts/` とプロジェクト直下に残しています。通常のアプリ運用では実行しません。
